# Follow-up: Routine Went First. Judgment Is Next.

Reproducible pipeline for the September 2026 follow-up post. Tests the March 2026 Delegation Resistance
model and Tyler Cowen's two-factor (Intelligence × Polanyi) model against BLS occupation employment,
May 2022–May 2025, and Indeed postings through September 2026.

**[Read the post](https://jbgh2.github.io/ai-worker-displacement/routine-went-first.html)** · [markdown source](../docs/routine-went-first.md) · [Pipeline spec with checkpoints](PIPELINE_SPEC.md)

## Run it

```
pip install -r requirements.txt
python scripts/02_fetch_onet.py        # O*NET 30.0, Dingel-Neiman, AIOE  (~65 MB)
python scripts/01_fetch_oews.py        # OEWS 2022-2025 via mirror + BLS API validation (~3,500 small files)
python scripts/03_build_panel.py       # indices + knowledge-work sample -> data/occupation_panel_2022_2025.csv
python scripts/04_analyze.py           # cells, regressions, figures -> results/, figures/
python scripts/05_indeed_postings.py   # Indeed postings by category via FRED -> results/
python scripts/06_ces_industries.py    # BLS CES industry series -> results/
pytest tests/                          # checkpoint assertions
```

Everything except the BLS API calls is cached under `data/raw/` after the first run. The BLS public
API allows ~25 unregistered calls per day; steps 01 and 06 use about 6.

## Layout

```
scripts/     numbered pipeline steps; common.py holds paths
tests/       checkpoint tests against results/summary.json and the panel
data/        occupation_panel_2022_2025.csv (the deliverable), oews_panel.csv, raw/ (cached sources)
results/     CSVs and summary.json written by 04-06
figures/     regenerated by 04_analyze.py (gitignored); the SVGs used by the post live in ../docs/
```

## Headline numbers (from `results/summary.json`)

218 teleworkable occupations, 49.1M workers, May 2022 → May 2025, all-occupation baseline +5.1%:

| | Not embedded (low Polanyi) | Embedded (high Polanyi) |
|---|---|---|
| Routine | **−2.6%** (15.3M) | +8.4% (6.8M) |
| Non-routine | +5.7% (5.7M) | +6.6% (21.3M) |

AIOE coefficient on employment change: +2.6 (SE 2.7). Communication friction: −0.03 (SE 0.97).
Intelligence: +4.2 (SE 1.6), the wrong sign for the two-factor model. Routine × Polanyi interaction in
2024→25: +0.85 (SE 0.40), the most significant term in that year's regression.

## Provenance and caveats

- BLS blocks bulk downloads from scripts. OEWS 2022–2024 come from a GitHub mirror of the published
  national tables ([Vabryn/bls](https://github.com/Vabryn/bls)), validated with zero mismatches against
  the BLS API (25 occupations, 2025) and against an independent copy of the 2022 table (653 occupations).
- AIOE comes bundled with that 2022 table from
  [augw999/ai-labor-market-impact_analysis](https://github.com/augw999/ai-labor-market-impact_analysis).
- OEWS pools three years of survey panels. BLS says not to use it as a time series. As in March, I did anyway.
- The routine index was specified after seeing that the losers spanned all four KWDM quadrants. See the
  post's methodology notes.
- The session in which this was developed, including predictions logged before each data pull, was run
  with Claude; the scripts here are a cleaned re-implementation and their outputs supersede the session's
  interim numbers (the session's Dingel-Neiman merge dropped customer service representatives; this one doesn't).
